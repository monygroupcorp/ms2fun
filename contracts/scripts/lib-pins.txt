# Pinned dependency set for the CI bootstrap of contracts/lib.
#
# WHY THIS FILE EXISTS
# contracts/lib is gitignored and holds no submodule gitlinks, so `actions/checkout` fetches no
# dependency source at all: a CI job starts with an empty lib/ and has to clone all of it. That
# bootstrap used to name only the repositories, which resolves to each dependency's default-branch
# HEAD -- so the same project commit compiled against different dependency code on different days,
# and an upstream push could red the gate with nothing changed here and no way to reproduce it
# locally. Every dependency is pinned to an exact commit here, and this file is the only place a
# dependency's URL or commit is written: the contracts workflow and the app workflow's
# bindings-drift step both install from it, so the two cannot drift apart. It replaces
# contracts/.gitmodules, which listed 11 of the 13 as bare URLs, pinned none of them, and -- with
# no gitlinks anywhere in the tree for it to describe -- was read by nothing.
#
# FORMAT
#   <scope>  <owner/repo>  <commit>
#
#   src   required to compile contracts/src. This is the set the app workflow's bindings-drift
#         step installs -- it builds src/ only, and deliberately not the two below.
#   test  additionally required by contracts/test and contracts/script.
#
# The two `test` entries are kept out of the src-only build on purpose: that build passes
# `--skip "*/test/**" "*/script/**"`, and adding dependencies src/ does not import only adds
# compile units that the skip globs then have to exclude.
#
# CHOICE OF REVISIONS
# These are the revisions the contracts are developed and tested against, recovered from the
# dependency trees themselves rather than from upstream HEAD: for each dependency, the working
# tree was hashed and matched against the upstream history, and every one resolved to exactly
# one commit. Pinning therefore records the status quo -- it does not move any dependency.
#
# MOVING A DEPENDENCY
# Edit its commit here, then run the full contracts gate (forge fmt --check, forge build, the
# EIP-170 + storage-layout gate, `FOUNDRY_PROFILE=ci forge test`, and the foundry.v4.toml
# RealSettlement run) and regenerate the wagmi bindings. A dependency move can change compiled
# bytecode and ABIs, so the bindings churn belongs in the same commit as the bump.
